# After 2AM - Late Night Life Companion

A mobile-first web app that feels like a quiet ordinary night after 2am.

**Emotional atmosphere:**
- Peaceful, calm, slightly lonely but safe
- Warm apartment lighting
- Late-night convenience store energy
- Quiet city life
- Soft emotional realism
- Minimalist & cinematic but subtle

**Features:**
- 🌙 Gentle task management
- 📝 Memory journal for late-night thoughts
- 🎵 Ambient soundscape companion
- 🔄 Weekly emotional summaries
- 🌍 Night mode selection
- ✨ Smooth, emotionally immersive UX

## Tech Stack
- React 18
- Tailwind CSS
- React Router
- Lucide React Icons

## Getting Started

```bash
npm install
npm run dev
```

## Screens
1. Home - Current time, location, emotional narration, main quests
2. Task Detail - Task info with emotional encouragement
3. Task Complete - Minimal celebration
4. Night Modes - Choose identity mode
5. Memory Journal - Late-night thoughts
6. After 2AM Radio - Ambient soundscape
7. Weekly Rhythm - Emotional summaries
8. Settings - Minimal configuration
9. Empty Night - No tasks atmospheric page
10. Onboarding - Cinematic introduction
